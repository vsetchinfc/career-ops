Agistra.Dev — Multi-Agent AI Delivery Framework (2025 – present)

An open-source, structured agent workspace and delivery framework built on Claude Code and the Claude API. Named agents (Architect, Builder, Tester, Router) each carry a defined identity, scoped role, behavioural constraints, tool access, and HOT/WARM/COLD memory — surfaced as native Cursor/VS Code custom agents selectable per session. Used in production for autonomous software delivery: a work item goes in, a tested PR comes out.

  • Designed the agent identity framework — separating role, persona, scope, system prompt, and prompt discipline — for predictable, auditable behaviour across multi-agent workflows
  • Implemented structured handoff contracts between agents: QA cannot start until every required field is populated — zero ambiguous hand-offs
  • Built HOT/WARM/COLD memory tiers so agent state survives across sessions and decays gracefully
  • Defined evaluation criteria and review standards for AI-generated code — what “good” looks like when an agent is the author
  • Tooling: TypeScript, Claude / Claude Code, GitHub Copilot (Agent Mode, sub-agents), MCP tooling, GitHub Issues & PR APIs, Telegram Bot API; event-driven task queue with a cloud dispatch adapter pattern
